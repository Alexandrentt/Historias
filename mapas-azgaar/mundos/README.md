# Mundos de Historias

Cada subcarpeta contiene un archivo `.map` original de Azgaar. Los seis archivos se han descomprimido y verificado localmente. La carga de los binarios a GitHub queda pendiente; las rutas están reservadas en `manifest.json`.


## Capas JSON editables de Azgaar

El índice de los seis mapas principales y el mapa auxiliar de tres continentes está en [capas-json/index.json](../capas-json/index.json). La extracción completa descargable incluye originales, capas JSON y mapas recompilados; consulta el README de esa carpeta para límites y validación.
