Mapa Atharis extraído de Atharis.map. Los datos guardados son una instantánea técnica de Azgaar y no confirman por sí solos topónimos, población, fronteras o eventos como canon narrativo.

La extracción íntegra —topología, campos físicos, atributos de celda, entidades empaquetadas, estilos, recursos SVG y utilidades de reconstrucción— se distribuye en el ZIP **Mapas_Azgaar_Capas_JSON_7_Mapas.zip** enlazado desde el proyecto. Este directorio de GitHub publica la ficha, auditoría y catálogos ligeros para navegación.  

Los datos generados por Azgaar no son canon narrativo automático. Las coordenadas de los exportes GIS son locales x/y y no WGS84. La recompilación conserva semánticamente los registros comparados; la serialización de JSON cambia bytes, por lo que el archivo reconstruido no es byte-idéntico.
